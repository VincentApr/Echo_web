# Illustration d'aperçu

[career-preview.png](career-preview.png) est un exemple générique sans données personnelles, généré
avec le skill **imagegen**, via l'outil intégré. Il sert uniquement à la simulation
locale du sujet de candidature. L'application utilise Mistral pour ses images.

Consigne finale utilisée :

> Use case: stylized-concept. Asset type: square background illustration for Echo intelligent watch cards, generic preview asset, no personal data. Create exactly one square editorial illustration, 1:1 aspect ratio: a sculptural open ivory notebook and a small sage envelope with a tiny olive branch on a quiet curved desk, an open window revealing a soft abstract landscape. Echo visual collection: restrained sculptural cut paper and matte ceramic, soft sage green, warm ivory, muted sand, tiny lavender accents, diffuse natural light, airy composition, subtle depth. Subject centered toward the right; calm slightly darker negative space at upper left and lower left for white text overlays added later in code. Elegant, sober and quiet. No writing, no letters, no logos, no numbers, no realistic people, no photorealism, no UI. This is a finished illustration, not a website mockup.
