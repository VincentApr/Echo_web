# Modèles fixes des notifications Echo

`friend.webp` et `group.webp` sont deux fonds sans texte, générés une fois avec
imagegen (outil intégré), puis normalisés par le pipeline WebP de l'application.
512 × 512, sans donnée personnelle. Le nom et le type d'événement sont affichés
en HTML pour rester exacts, lisibles et à jour, sans appel IA.

Les originaux et les consignes se trouvent dans
`scripts/fixtures/watch-covers/native-originals/` et `native-prompts.json`.
Référence artistique : la pochette GitHub du prototype validé, utilisée comme
référence de style, avec une palette propre à chaque modèle natif.
